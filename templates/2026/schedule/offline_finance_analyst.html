Building an Offline Personal Finance Analyst in Python with Ollama

Saturday, 10 October 2026 15:45 – 16:15 Majestic Hall

Calvin Magezi

Sponsor Talk, Kolaborate

Abstract

Your phone already holds your financial history: mobile money confirmations, airtime top-ups and payments. In this 30-minute hands-on session, we build an offline personal finance analyst in Python that reads those messages and shows where your money went, without sending a single message to the cloud.

We start by exporting messages from an Android phone, redacting personal details, and parsing amounts in UGX with regular expressions and pandas. Then we add a small open language model running locally through Ollama to categorise the messages our rules miss and to write a plain-language summary. Python does all the arithmetic and the model only handles language, so the numbers stay exact.

We finish by testing where the model gets things wrong, such as slang, typos and ambiguous messages, and how to catch those mistakes. Once set up, everything runs offline with no API keys. You will leave with a working notebook and a pattern you can reuse for any private, local data.
