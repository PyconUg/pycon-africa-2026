Persons of Concern Program

PyLadies Kampala Refugee Python Workshop

As part of PyCon Africa 2026's commitment to making technology education more accessible, the Persons of Concern Program will host a dedicated Python and Django workshop for refugees and other undeserved communities.

Organized by PyLadies Kampala, this initiative provides participants with an opportunity to develop practical software development skills through a hands-on learning experience led by experienced Python developers, mentors, and community leaders.

Building on the success of previous PyLadies outreach programs — including the Arua Refugee Python Web Development Bootcamp that introduced more than 100 participants to Python and web development — this workshop continues our mission of creating inclusive pathways into technology.

Whether participants are taking their first steps in programming or looking to strengthen existing skills, the workshop offers an encouraging environment focused on learning, collaboration, and community.

About the Workshop

This workshop introduces participants to modern Python web development using Django through practical, instructor-led sessions.

Rather than focusing on theory alone, attendees will work through real coding exercises, build a functioning web application, and gain exposure to tools commonly used by software developers.

Throughout the day, mentors will provide one-on-one guidance, helping participants build confidence while developing problem-solving skills and practical programming experience.

What Participants Will Learn

Python Fundamentals

Learn programming fundamentals including variables, data types, functions, loops, and control flow.

Introduction to Django

Understand how Django helps developers build secure and scalable web applications.

Build a Web Application

Create a simple web application from scratch using Django.

Version Control with Git

Learn how developers use Git and GitHub to manage and share projects.

Collaborative Learning

Work alongside mentors and fellow participants in an inclusive learning environment.

Who Should Attend

The workshop is intended for:

Refugees and displaced persons

Undeserved youth interested in technology

Beginners with little or no programming experience

Students interested in software development

Women and underrepresented groups in technology

No previous programming experience is required.

Why This Program Matters

Access to quality technology education remains limited for many displaced and undeserved communities.

By providing practical software development training, mentorship, and access to the wider Python community, this program seeks to reduce barriers to digital skills development while creating opportunities for continued learning, employment, entrepreneurship, and participation in open source communities.

The workshop also reflects PyCon Africa's commitment to diversity, inclusion, and community empowerment across the continent.

Expected Outcomes

Participants will:

Gain foundational Python programming skills

Build and deploy their first Django application

Learn collaborative software development practices using Git and GitHub

Connect with mentors from the African Python community

Join local technology communities for continued learning beyond the workshop
